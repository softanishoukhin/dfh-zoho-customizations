# Release Notes — 2026-09-23

## ZP-TBD-75 — Pre-Need payment schedule rework
Confirmed complete via live testing. `button.calculateInstallmentAmount` (Deals) rewritten from a
fixed 3-way equal split (driven by org variable `Total_Installments`, hardcoded `3`) to a date-derived
schedule: `Contract_Value - Pre_Need_Deposit_Amount` is now split evenly across however many monthly
periods fall between two new Deals fields, `Installment_Commencement_Date` and
`Installment_Day_of_Month`, and `Pre_Need_Balance_Due_Date` (reused as-is, already live) — the balance
due date is always the final period, capped at the 3 existing `Installment_1/2/3_Amount`/`_Due_Date`
slots. `standalone.createInstallmentInvoice` (`createinstallments`) got a defense-in-depth guard
against a blank/zero installment slot, since the old fixed-3 logic always populated all three slots and
never needed one.

Two things caught during this build that aren't specific to this task, now standing rules:
`zoho.crm.updateRecord` from inside a function doesn't fire workflow rules unless
`{"trigger":{"workflow"}}` is passed explicitly (confirmed live: singular `"trigger"` is correct) — the
old function got away without this because staff typed due dates in manually via the UI, a real edit
that fires workflows on its own, and this rewrite is the first time `calculateInstallmentAmount` has
ever needed to trigger `automation.handleWorkflowTriggerAndActionByTimelineProcess` (the dispatcher
that actually creates the installment invoices) programmatically. Separately, `getRecordById` returns
Date/Number fields as String, not native type — relational comparisons need an explicit `.toDate()`/
`.toLong()` first or Deluge throws "Comparison of non numeric expression is not supported".

Full build record: `crm/functions/deals/ZP-TBD-75_preneed_payment_schedule_rework/` (metadata.md,
guideline.md, `*_UPDATED.deluge`, `rollback/*_CURRENT.deluge`).

Still open, non-blocking: rounding intent to confirm with Andrea against the real contract, and a
decision on deprecating the now-fully-dead `Number_of_Installments` picklist / orphaned
`Total_Installments` org variable.
